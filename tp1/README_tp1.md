# Assignment 1: Environment Setup & Basic System Info

# Soufiane Yagoubi

## Project Description
This repository contains the first assignment for the Operating Systems course (2026). The objective is to set up the development environment and execute a Bash script capable of retrieving and displaying basic system information within a cloud environment (Killercoda / Google Colab).

The `info.sh` script extracts the following data:
1. Operating System name and Linux kernel version.
2. The current logged-in user on the machine.
3. The current working directory path.
